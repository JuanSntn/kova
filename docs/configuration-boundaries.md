# Límites de configuración: negocio y sucursal

## Cuenta

Una cuenta de usuario puede pertenecer a varios negocios. Cada negocio es un tenant independiente: tiene su propio contrato, catálogo, inventario, personal y sucursales.

## Negocio

El negocio define lo que debe ser consistente para toda la marca: nombre, logotipo, correo público, teléfono general, configuración visual y de impresión de tickets, impuestos, perfil fiscal y suscripción.

## Sucursal

La sucursal representa una ubicación que opera dentro de un negocio. Define nombre, código, dirección, código postal, zona horaria, teléfono operativo local, disponibilidad y precio local de productos, personal asignado, caja y serie fiscal cuando aplique.

Los tickets usan una única configuración del negocio y siempre toman el logotipo, teléfono y correo público de la marca. En cada venta muestran, si está habilitado, los datos dinámicos de la sucursal que realizó la venta. La configuración fiscal por sucursal se mantiene porque el lugar de expedición y la serie pueden variar.
